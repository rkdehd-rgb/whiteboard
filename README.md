# M²Studio · 协作白板

单文件协作白板 + 零依赖 WebSocket 中继。打开一个 HTML 就能画，起一个 Node 脚本就能多人实时协作。

- **零依赖**：`whiteboard.html` 不引用任何 CDN 或框架，单文件约 265KB，断网可用
- **零构建**：没有打包步骤，改完刷新即生效
- **双通道同步**：同一浏览器多窗口走 `BroadcastChannel`，跨设备走 WebSocket 中继

---

## 快速开始

### 一个人用（本地文件）

直接双击 `whiteboard.html`，或拖进浏览器。

数据存在本机 `localStorage` + `IndexedDB`，关掉再打开内容还在。

### 多人协作（起中继）

```bash
node relay-server.js
```

然后访问 `http://localhost:8787`（同一局域网的同事用 `http://<你的IP>:8787`）。

中继同时托管页面和 WebSocket，一个端口搞定；没装依赖，`node` 直接跑。

Windows 下也可以双击 `启动中继.bat`。

### 分房间

地址后加 `#room=房间号`，同名房间才互通：

```
http://192.168.1.10:8787/#room=a1
```

房间号只能用字母、数字、下划线、点、横线（1–64 字符）；**中文会被中继归到公共房间**，请用拼音或英文。
不带参数时进公共白板（房间 `main`）。

## 功能

### 画布与内容

| 对象 | 说明 |
|---|---|
| 便签 | 双击编辑，可换色，支持多行与自动字号 |
| 图形 | 矩形 / 圆角矩形 / 椭圆 / 菱形 / 三角形 / 直线 / 箭头，**按下定位、拖动定尺寸、松手创建**（Shift 约束正方形） |
| 自由文本 | 双击进入编辑，独立字号与颜色 |
| 图片 | 按原始像素尺寸插入；默认锁定长宽比，Shift 临时自由拉伸 |
| 画笔 | 压感无关的平滑笔画，支持颜色与粗细 |
| 连线 | 可连到便签/图片/图形/文本/评论，带起终点箭头、虚线、粗细 |
| 图框 | 默认 1920×1080，可选 2×、4×，导出按 1:1 渲染 |
| 评论 | 图钉批注 + 留言线程，可标记解决 |

### 编辑效率

- 多选、框选、复制、置顶置底、删除，撤销/重做 80 步
- 拖动时与其它元素的边/中线**自动吸附**，并显示对齐参考线
- 图层面板：按层级排序、逐项显隐（显隐会同步给协作者）
- 样式面板：填充、描边、颜色、透明度、粗细、虚线、字号、对齐
- 多白板存档：右上角「白板存档」，每块板独立保存、独立房间

### 导出

| 方式 | 说明 |
|---|---|
| PNG | 整板或按图框分页；分页时打包为单个 zip |
| PDF | A4，多页对应多个图框 |
| 剪贴板 | 直接粘贴到其它应用（剪贴板不支持分页） |
| 高清档 | 长边 5200；图框分页恒按 1:1，不降采样 |
| 工程文件 | `.json`，含 8 类对象 + 图片本体 + 视口与版本号；导入时新建一块白板，不覆盖当前内容 |

按图框分页时会去掉图框底色、标签条、比例文字和网格，页面里只留框内实际内容。

### 协作

- 实时同步操作，协作者光标带姓名色块
- 成员列表与在线人数
- **自定义我的名字与颜色**：点顶栏自己的头像（或协作面板里的「改名」），改名后协作者立刻在光标、成员列表里看到；名字与颜色存在本机，刷新、换标签页都保留
- 新成员入会拉取房间快照
- 中继可选访问口令（见下方参数）
- 断线自动重连；切回窗口时补发握手

### 其它

- 中英双语界面（「白板存档」面板底部切换）
- 触摸设备支持**双指缩放与双指平移**
- 键盘焦点框、`aria` 标注、`prefers-reduced-motion` 降级
- 数据 schema 带版本号与迁移链，旧数据可平滑升级

## 中继参数

```bash
node relay-server.js [选项]
```

| 参数 | 默认值 | 说明 |
|---|---|---|
| `--port` | `8787` | 监听端口（也读 `PORT` 环境变量） |
| `--dir` | `./rooms` | 房间快照落盘目录 |
| `--no-save` | 关闭 | 只做实时转发，不落盘 |
| `--page` | `./whiteboard.html` | 顺便托管的页面文件 |
| `--token` | 无 | 开启访问口令，不匹配返回 401 |
| `--maxconn` | `500` | 并发连接上限，超出返回 503 |
| `--ratemsg` | `120` | 单连接每秒消息数上限，超限以 1008 关闭 |
| `--snapmb` | `12` | 单房间快照体积上限（MB） |
| `--snaprooms` | `200` | 内存中保留的房间快照数（LRU 淘汰） |

开启口令后，访问地址需要带 `?token=你的口令`，页面会自动把它带到 WebSocket 连接上。

> 口令是明文比对，`ws://` 不加密。局域网用没问题；放到公网请走反向代理并开启 TLS。

详细的服务器搭建说明见 `协作白板服务器搭建说明.md`（同目录还有 `.html` 与 `.pdf` 版本）。

## 测试

回归基线零依赖，用本机 Chrome 跑真实页面（`CHROME` 环境变量可指定其它路径）。

```bash
node test/run.js              # 全部主线，约 30 秒
node test/run.js shape pinch  # 只跑指定主线
TIMEOUT=120 node test/run.js  # 放宽单条主线超时（秒）
```

| 主线 | 覆盖 |
|---|---|
| `export` | 图框导出 1:1、分页干净页、高清档、zip 结构 |
| `sync` | 双窗口双向同步、恶意消息清洗、关闭前落盘 |
| `op` | 7 类操作的序列化往返、非法字段拒绝、数值夹取、schema 迁移 |
| `relay` | 口令鉴权、连接上限、消息限流、快照体积与 LRU |
| `perf` | 全量重绘是否被跳过、网格图案缓存 |
| `ui` | a11y 属性、中英切换 |
| `img` | 图片按原始像素插入、重编码后尺寸不变 |
| `pinch` | 双指缩放锚点、上下限、误触回滚 |
| `shape` | 拖拽创建、最小尺寸、Esc 取消、吸附 |
| `profile` | 身份弹层、名字清洗与截断、落盘持久化、`who` 广播改名 |
| `project` | 工程结构、图片随包、JSON 往返、导入还原、脏数据清洗、非法文件拒绝 |

测试不会污染交付文件：`run.js` 每次把 `whiteboard.html` 复制到 `test/.tmp/app.html`，只在副本里注入探针。

## 技术说明

### 渲染分层

```
#board / #ink     canvas：网格、笔画（屏幕坐标，随缩放重绘）
#world            CSS transform 世界层
  #frames         SVG  图框
  #shapes         SVG  图形
  #edges          SVG  连线
  #notes          DOM  便签
  #texts          DOM  自由文本
  #comments       DOM  评论图钉
#overlay          canvas：选框、手柄、对齐参考线、协作者光标
```

世界层用一次 `transform: translate() scale()` 完成所有元素的位移与缩放；两层 canvas 按当前视图重绘。

### 操作模型

所有改动都表示为一组 op（`note.add` / `shape.update` / `image.remove` …）：

- 本地执行 `applyOp` → 广播 → 写入撤销栈
- 远端收到的 op 先过字段白名单与类型校验，再进入同一套 `applyOp`
- 未知 op、超范围数值、非法色值与 id 一律丢弃

这样同一条代码路径同时保证本地编辑与协作同步的一致性，也让持久化格式天然可回放。

### 同步与冲突

| 层 | 机制 |
|---|---|
| 同浏览器多窗口 | `BroadcastChannel`，按房间号隔离 |
| 跨设备 | WebSocket 中继，同房间广播 |
| 冲突 | 按元素 `ts` 的最后写入优先（LWW），并发编辑同一元素可能互相覆盖 |
| 新成员 | 入会时向房间索取整份快照 |

### 持久化

- `localStorage`：白板索引、文档元数据、视图状态，带 `v` 版本号与迁移函数
- `IndexedDB`：图片本体（避免撑爆 localStorage 配额），加载时按需回填
- 中继 `rooms/*.json`：房间快照，供新成员入会与重启恢复

## 已知限制

| 限制 | 说明 |
|---|---|
| 冲突解决为 LWW | 两人同时改同一个元素，后到的覆盖先到的 |
| 无用户身份 | 中继只有房间口令，无法按人授权或审计"谁改的"；名字与颜色只是本机自填的显示名，不做校验、不跨设备同步 |
| PDF 为位图 | 文字不可选中、不可检索（换取清晰度） |
| 跨域图片无法导出 | 源站不允许跨域读取时，导出会跳过并在提示里报数量 |
| 中继快照不随部署迁移 | 重新部署容器会从空开始，长期保存请用「白板存档」或导出 |
| 工程文件不含协作状态 | 只带内容与视口；房间号、成员身份、界面语言、本地设置不写入 |
| 极端尺寸会降采样 | 导出有 40MP / 12000px 上限，4× 图框（7680×4320）会比较慢 |
| 大图存储上限 | 超过 4096px 或 1.2MB 的图片会重编码压缩（插入尺寸仍按原图记录） |

## 浏览器要求

Chrome / Edge 90+、Firefox 90+（需要 `PointerEvent`、`BroadcastChannel`、`IndexedDB`）。

Safari 需要 15.4 以上（`BroadcastChannel` 从 15.4 才提供），且**尚未实测**；iOS 上的双指缩放与 `touch-action` 行为也未逐一验证。

`file://` 下也能用，但多窗口协作需要同源，请起中继后通过 `http://` 访问。
